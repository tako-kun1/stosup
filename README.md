# Stosup — 配信者補助ソフトウェア

**Stosup** は、YouTube Live などのライブ配信をもっと楽しく・スムーズに運営するための Windows 向け配信者補助ソフトウェアです。
コメントの強調表示、特定ワードの自動カウント、ユーザー抽選・コメント抽選、視聴者リスト管理、OBS Studio 向けオーバーレイ表示までを 1 つのアプリで完結できます。

> **対応プラットフォーム**: 現在 **YouTube Live** に対応しています（今後のアップデートで他プラットフォームにも順次対応予定です）。

---

## 主な機能

### 1. トークモニター ＆ ハイライトサイン（コメント表示・絵文字スタンプ・検索・NG ワード防御）
- 配信チャットをリアルタイムでアプリ内に表示し、**YouTube カスタム絵文字・メンバースタンプ・スーパーステッカーの画像表示**に対応しています。
- 配信 URL / 動画 ID のほか、**チャンネル URL / `@ハンドル` からのライブ枠自動検出**・**接続履歴＆お気に入りチャンネル登録**・**回線瞬断時の自動再接続**に対応しています。
- 本文・投稿者名・名前メモの**リアルタイム検索＆7 種フィルタ（初見 / メンバー / エール / ハイライト / 質問 / NG 該当）**と、**NG ワード防御（完全非表示 / OBS のみ非表示 / 伏せ字マスク）**を備えています。
- 「初見」「質問」「おめでとう」など **特定のワードを含むコメントの吹き出し背景色・文字色・枠線色を自動変更** できます（部分一致・完全一致・正規表現に対応）。
- アプリ画面だけでなく、OBS のトークモニターオーバーレイにもそのまま反映されます。

### 2. コールカウンター（特定ワード集計）
- 指定したワードがコメントされた回数をリアルタイムにカウントします。
- カウンターごとに以下の 2 種類の集計方式を選択できます：
  - **アカウント毎に n 回まで**（例：1人1回までのアンケート・参加人数集計）
  - **回数上限なし**（例：「草」や応援コメントの総数カウント）

### 3. ドローボックス（ユーザー抽選 ＆ コメント抽選）
- **ユーザー抽選**: リスナー名簿からランダムに当選者を選びます（**1度のみ / 複数回**の切替に対応）。
- **コメント抽選**: **開始コメント** と **終了コメント** を自動で配信チャットに投稿し、その間に特定ワードを含むコメントをした視聴者から抽選します（1ユーザー1口 / 複数口・当選人数を自由に設定可）。
- 当選者の **アイコンと名前** をアプリ内および OBS オーバーレイ（ルーレット演出付き）に表示します。

### 4. リスナー名簿・名前メモ ＆ アプリ内 BAN 管理
- コメントに参加した視聴者を自動でリスト化し、**視聴回数**（1配信につき1回でもコメントすると +1）と **コメント回数** を自動記録して表示します。
- 各視聴者に **名前メモ** を登録すると、トークモニターの名前の横にメモが表示され、コメント欄からその場で編集することもできます。
- 迷惑ユーザーなどを Stosup 内で **BAN** すると、ドローボックス・コールカウンター・ウェルカムカウンター等に一切参加できなくなります。
- 不要な視聴者を名簿から **個別削除** したり、名簿全体を **一括リセット**（BAN 済みユーザーは残すオプション付き）することもできます。

### 5. ウェルカムカウンター（初見さん検知）
- リスナー名簿に未登録の視聴者の初回コメント、または「初見」などのワード発言を **1 アカウントにつき 1 度だけ** 検知してカウントします。
- 配信のたびに表示カウントを 0 にリセットでき（過去の検知履歴は維持）、オプションで **初見さんのアイコンと名前を表示（デフォルトはオフ）** することもできます。

### 6. エールボックス（スパチャ・メンバー管理 ＆ お礼チェック）
- スーパーチャット・スーパーステッカー・メンバーシップ新規加入・継続・ギフトを専用画面で一覧表示し、**お礼済みチェック**・未読フィルタで読み忘れを防止できます。
- トークモニター上でもティア色・金額バッジで強調表示され、専用 OBS オーバーレイ（未読のみ表示 `?unread_only=1` 対応）も利用できます。

### 7. ライブアンケート ＆ スポットテロップ
- **ライブアンケート**: 視聴者コメントの番号やキーワードを **1 アカウント 1 票** で自動集計し、アニメーション付き棒グラフと投票方法ガイドを OBS オーバーレイに表示します。
- **スポットテロップ**: トークモニター・エールボックスから任意のコメントを **1 クリックで OBS 上に大きくピン留め表示**（質問返し・注目コメント紹介）し、ワンクリックで解除できます。

### 8. エントリーレーン（参加型順番待ち管理）
- 「参加希望」「辞退」コメントで待機列を自動管理し、同時参加枠管理・**初見さん優先 / 参加回数少ない人優先** の並び替え・空き枠繰り上げ・一括交代を簡単に行えます。

### 9. リアクションステージ（アニメーション・動画・効果音演出）
- コメント（複数行ワード・全コメント）や **スパチャ・メンバーシップ・初見さん** に反応して、**固定表示（画像・GIF・透過 WebM / MP4 動画）・クラッカー・落下物・紙吹雪・投てき・環境演出（雪・桜吹雪・雨・キラキラ・ハート・火の粉）** を軽量なオフスクリーンスプライト描画エンジンで滑らかに再生できます。
- 各演出に **効果音（MP3 / WAV / OGG）** を同時再生でき、再生方式（順番待ち / 重ね表示 / 上書き）、複数同時発動の ON/OFF、**リアクションステージの背景色（透過／クロマキー緑・青／自由カラー選択）** もワンクリックで即時変更できます。

### 10. ポケットスイッチャー（LAN 接続 ＆ スマホ・別端末リモコン `/remote`）
- 同じ Wi-Fi / LAN 内のスマートフォン・タブレット・サブ PC のブラウザから Stosup をリアルタイム操作できます（外部インターネット IP からの接続は常にブロックされます）。
- **アクセス PIN コード認証**、**スキャンで即接続できる QR コード表示**、**LAN IP (`192.168.xxx.xxx` 等) 自動検出**、**Windows ファイアウォール許可コマンドコピー** に対応しています。
- スポットテロップ・チャット投稿・エールボックスお礼チェック・リアクションステージのワンタップ発動＆演出追加/編集/削除/素材アップロード・ライブアンケート・エントリーレーン・コールカウンター・ドローボックス・機能 ON/OFF に対応し、PC 側アプリと他の LAN クライアント間で設定がリアルタイムに双方向同期されます。

### 11. オーバーレイスタジオ（OBS ブラウザソース ＆ デザインカスタマイズ）
- 以下の **9 つのオーバーレイ画面** をローカル URL として内蔵しています（OBS の「ブラウザ」ソースに貼るだけで利用可能）：
  - **トークモニター**: `http://127.0.0.1:18765/overlay/comments`
  - **エールボックス**: `http://127.0.0.1:18765/overlay/superchat`
  - **スポットテロップ**: `http://127.0.0.1:18765/overlay/pickup`
  - **ライブアンケート**: `http://127.0.0.1:18765/overlay/poll`
  - **エントリーレーン**: `http://127.0.0.1:18765/overlay/queue`
  - **リアクションステージ**: `http://127.0.0.1:18765/overlay/media`
  - **ドローボックス**: `http://127.0.0.1:18765/overlay/lottery`
  - **コールカウンター**: `http://127.0.0.1:18765/overlay/counter`
  - **ウェルカムカウンター**: `http://127.0.0.1:18765/overlay/first_time`
- すべてのオーバーレイごとに **6 種類の洗練されたスタジオプリセット**（`オンエア・テロップ` / `クリーン・マガジン` / `タクティカル・HUD` / `バラエティ・テロップ` / `シネマ・クリア字幕` / `エッジ・グロウ`）を用意しています。
- CSS を書かなくてもソフト単体で細かくデザインを作り込める **GUI ビジュアルスタイルエディタ** を搭載し、**文字サイズ・ウェイト・字間・行間・2 色文字グラデーション・袋文字（縁取り＋二重フチ）・テキストエッジ発光・ドロップシャドウ・カード背景透明度・角丸・枠線・影・出現モーション** をリアルタイムプレビュー付きで編集できます。本番データに一切影響しない **プレビュー専用環境（`/overlay/preview/*`）** での実寸確認・テストデータ送信や、他オーバーレイへのスタイルコピー、上級者向けカスタム CSS 上書きにも対応しています。

### 12. 連携・オートメーション（OBS WebSocket v5 ＆ ホットキー / Stream Deck 対応）
- **OBS WebSocket v5 連携**: OBS の配信開始を検知してウェルカムカウンターやコールカウンターを自動リセットしたり、スパチャ・メンバー加入・特定ワード・抽選当選をトリガーに **OBS シーン切替やソースの表示／非表示（タイマー自動復帰付き）** を自動実行できます。
- **グローバルホットキー ＆ Stream Deck トリガー**: ゲームをフルスクリーンでプレイ中でも、登録したショートカットキーや Stream Deck 向けローカル HTTP トリガー URL（`/api/trigger/...`）からスポットテロップ解除・リアクション発動・アンケート締切・OBS 操作などを一発実行できます。

### 13. オンエアレポート（配信振り返り ＆ 盛り上がりグラフ）
- 配信セッションごとの **総コメント数・ユニーク視聴者数・初見人数・分速コメント数・エール集計** を自動記録します。
- **1 分刻みの盛り上がり推移グラフ** と **盛り上がりピーク TOP 5（経過タイムスタンプ＋代表コメント抜粋）**・頻出ワード TOP 15・アクティブ視聴者 TOP 10 を可視化し、切り抜きポイント探しや活動記録に便利な **CSV（Excel 互換 UTF-8 BOM 付き） / JSON エクスポート** に対応しています。

### 14. 配信プロファイル切替 ＆ フルバックアップ / PC 引っ越し
- 雑談枠・ゲーム参加型枠・歌枠など企画に合わせて、機能 ON/OFF・オーバーレイデザイン・ルール有効状態を **プロファイルとして保存しサイドバーから 1 クリック切替** できます。
- データベース・設定・リスナー名簿・リアクション素材ファイルを 1 つの ZIP に書き出し・復元できる **バックアップ / PC 引っ越し機能**（復元前の自動退避＆起動時の最大 5 世代自動バックアップ付き）を備えています。

### 15. 自動アップデート ＆ リリースノート表示
- 新しい正式版が GitHub に公開されると自動で通知し、アプリ内からそのまま最新版へアップデートできます。
- アップデート後の初回起動時には、そのバージョンで何が変わったか（リリースノート）を自動で表示します。
- バージョン表記に `pre` が付く先行版は自動更新の対象外となり、設定画面の「先行版（pre）の更新アナウンスを含める」（既定: オフ）をオンにした場合のみ案内を表示します。案内ダイアログからは内容を確認したうえで手動操作によりソフト内から更新できます。同一ナンバリングの正式版がある場合は正式版が優先されます。

### 16. 各機能の ON / OFF 切り替え ＆ ライト／ダークモード
- 全 16 機能を配信スタイルに合わせて **個別に ON / OFF** できます。
- 「設定・機能管理」画面から **ライトモード / ダークモード / システム設定に従う** を切り替えられます。

### 17. 演出 MOD 拡張（独自演出／追加テーマ／独自オーバーレイ／ロジックスクリプト）
- 専用画面 **「MOD 管理」** から `.stosupmod` / `.zip` の導入、または `%APPDATA%\Stosup\mods\` フォルダ配置＋再読み込みで、ユーザー作成の演出 MOD を追加できます（**特別なビルド環境やコンパイル作業は不要**です）。
- 統一マニフェスト `mod.json`（`schema_version: 1`）により、**① リアクションステージ独自演出（JS / CSS・GUI カスタムパラメータ対応）**、**② 全 9 種 OBS オーバーレイ追加テーマ（CSS / 任意 JS フック）**、**③ 独立カスタムオーバーレイ（`/overlay/mod/{mod_id}/{overlay_id}` ＋ `StosupMod` JS SDK）**、**④ ロジックスクリプト（組み込みスクリプト言語 Rhai `.rhai` によるコンボ／状態管理・動的演出発火・OBS 自動操作・リアルタイムデバッグログ）** の 4 種類すべてに対応しています。
- 制作者向けガイド・API リファレンス・実働サンプル集を用意しています：
  - [演出 MOD 開発公式ガイド](./docs/MOD_DEVELOPMENT.md)
  - [ロジックスクリプト開発ガイド（.rhai）](./docs/MOD_SCRIPT_GUIDE.md)
  - [MOD API & オーバーレイリファレンス](./docs/MOD_API_REFERENCE.md)
  - [実働サンプル MOD 集](./examples/mods/README.md)

## 動作環境

- **OS**: Windows 10 / Windows 11 (64bit)
- 管理者権限は不要です（ユーザー領域へ安全にインストールされます）。

---

## インストール方法

1. [GitHub Releases](https://github.com/tako-kun1/stosup/releases) ページから最新版の `Stosup-vX.Y.Z-x64.msi` をダウンロードします。
2. ダウンロードした `.msi` ファイルを実行し、日本語の利用規約を確認・同意のうえ、お好みのインストール先フォルダー（既定は `%LOCALAPPDATA%\Stosup`、管理者権限不要）へインストールしてください。
3. スタートメニューまたはデスクトップの「Stosup」から起動します。

## かんたんな使い方

### Step 1: 配信に接続する
1. 画面上部の入力欄に **YouTube Live の配信 URL**（または 11 文字の動画 ID）を貼り付け、「接続」をクリックします。
   - 通常のコメント取得（InnerTube モード）はログイン設定なしですぐに利用できます。
   - 配信をしていない状態で試したい場合は、**「デモ配信」ボタン**から仮想コメントを使って全機能を体験できます。

### Step 2: OBS Studio にオーバーレイを追加する（任意）
1. Stosup の「オーバーレイスタジオ」メニューから使いたいオーバーレイの URL をコピーします。
2. OBS Studio でソースの「＋」→「ブラウザ」を追加し、コピーした URL を貼り付けます。
3. 背景は自動で透過されるため、そのまま配信画面の好きな位置に配置できます。

### Step 3: コメント抽選の自動投稿を使う場合（YouTube OAuth 連携）
- コメント抽選で開始コメント・終了コメントを YouTube チャットへ自動投稿する場合は、「設定」画面の **YouTube アカウント連携 (OAuth 2.0)** で Google アカウントを連携してください。

## アップデート方法

1. 新バージョンが公開されると、Stosup 起動時または「設定」→「アップデートを確認」から通知が表示されます。
2. 変更内容を確認し「ダウンロードしてアップデート」をクリックすると、自動で最新版をインストールして再起動します。
3. 再起動後に変更点（リリースノート）が表示されます。
