# Stosup — 配信者補助ソフトウェア

**Stosup** は、YouTube Live などのライブ配信をもっと楽しく・スムーズに運営するための Windows 向け配信者補助ソフトウェアです。
コメントの強調表示、特定ワードの自動カウント、ユーザー抽選・コメント抽選、視聴者リスト管理、OBS Studio 向けオーバーレイ表示までを 1 つのアプリで完結できます。

> **対応プラットフォーム**: 現在 **YouTube Live** に対応しています（今後のアップデートで他プラットフォームにも順次対応予定です）。

---

## 主な機能

### 1. コメント表示 ＆ 特定ワード反応（吹き出しの色変更）
- 配信チャットをリアルタイムでアプリ内に表示します。
- 「初見」「質問」「おめでとう」など **特定のワードを含むコメントの吹き出し背景色・文字色・枠線色を自動変更** できます（部分一致・完全一致・正規表現に対応）。
- アプリ画面だけでなく、OBS のコメントオーバーレイにもそのまま反映されます。

### 2. 特定ワードカウンター
- 指定したワードがコメントされた回数をリアルタイムにカウントします。
- カウンターごとに以下の 2 種類の集計方式を選択できます：
  - **アカウント毎に n 回まで**（例：1人1回までのアンケート・参加人数集計）
  - **回数上限なし**（例：「草」や応援コメントの総数カウント）

### 3. 抽選システム（ユーザー抽選）
- 配信に参加した視聴者の中からランダムに当選者を選びます。
- **「1度のみ（一度当選した人を除外）」** と **「複数回（何度でも当選可能）」** の切り替えに対応。
- 当選者の **アイコンと名前** をアプリ内および OBS オーバーレイ（ルーレット演出付き）に表示します。

### 4. コメント抽選システム
- **開始コメント** と **終了コメント** を自動で配信チャットに投稿し、その間に特定ワードを含むコメントをした視聴者から抽選します。
- 1ユーザー1口 / 複数口、1度のみ / 複数回、当選人数を自由に設定できます。

### 5. 視聴者リスト・名前メモ ＆ アプリ内 BAN 管理
- コメントに参加した視聴者を自動でリスト化し、**視聴回数**（1配信につき1回でもコメントすると +1）と **コメント回数** を自動記録して表示します。
- 各視聴者に **名前メモ** を登録すると、アプリ内のコメント欄の名前の横にメモが表示され、コメント欄からその場で編集することもできます。
- 迷惑ユーザーなどを Stosup 内で **BAN** すると、ユーザー抽選・コメント抽選・ワードカウント・初見カウンターに一切参加できなくなります。
- 不要な視聴者をリストから **個別削除** したり、リスト全体を **一括リセット**（BAN 済みユーザーは残すオプション付き）することもできます。

### 6. 初見カウンター
- Stosup に未登録の視聴者の初回コメント、または「初見」などのワード発言を **1 アカウントにつき 1 度だけ** 検知してカウントします。
- 配信のたびに表示カウントを 0 にリセットでき（過去の検知履歴は維持）、オプションで **初見さんのアイコンと名前を表示（デフォルトはオフ）** することもできます。

### 7. スーパーチャット / メンバーシップ専用管理 ＆ 読み忘れチェック
- スーパーチャット・スーパーステッカー・メンバーシップ新規加入・継続・ギフトを専用画面で一覧表示し、**お礼済みチェック**・未読フィルタで読み忘れを防止できます。
- 通常コメント欄・コメントオーバーレイ上でもティア色・金額バッジで強調表示され、専用 OBS オーバーレイ（未読のみ表示 `?unread_only=1` 対応）も利用できます。

### 8. リアルタイム投票 / アンケート ＆ コメントピックアップ（ピン留め表示）
- 視聴者コメントの番号やキーワードを **1 アカウント 1 票** で自動集計し、アニメーション付き棒グラフと投票方法ガイドを OBS オーバーレイに表示します。
- コメント一覧・スパチャ一覧から任意のコメントを **1 クリックで OBS 上に大きくピン留め表示**（質問返し・注目コメント紹介）し、ワンクリックで解除できます。

### 9. 参加型キュー（順番待ちリスト）管理
- 「参加希望」「辞退」コメントで待機列を自動管理し、同時参加枠管理・**初見さん優先 / 参加回数少ない人優先** の並び替え・空き枠繰り上げ・一括交代を簡単に行えます。

### 10. WordParty 形式の特定ワード反応演出（パーティクル・画像・動画・効果音）
- コメント（複数行ワード・全コメント）や **スパチャ・メンバーシップ・初見さん** に反応して、**固定表示（画像・GIF・透過 WebM / MP4 動画）・クラッカー・落下物・紙吹雪・投てき・環境演出（雪・桜吹雪・雨・キラキラ・ハート・火の粉）** を軽量なオフスクリーンスプライト描画エンジンで滑らかに再生できます。
- 各演出に **効果音（MP3 / WAV / OGG）** を同時再生でき、再生方式（順番待ち / 重ね表示 / 上書き）、複数同時発動の ON/OFF、**WordParty オーバーレイの背景色（透過／クロマキー緑・青／自由カラー選択）** もワンクリックで即時変更できます。

### 11. ローカルネットワーク (LAN) 接続 ＆ Web リモートコントロール (`/remote`)
- 設定画面から **「ローカルネットワーク内の他端末からの接続を許可する」** を ON にすると、同じ Wi-Fi / LAN 内のスマートフォン・タブレット・サブ PC のブラウザから Stosup を操作できます（初期設定は OFF、外部インターネット IP からの接続は常にブロックされます）。
- **アクセス PIN コード認証**、**スキャンで即接続できる QR コード表示**、**LAN IP 自動検出**、**Windows ファイアウォール許可コマンドコピー** に対応しています。
- コメントピックアップ・チャット投稿・スパチャお礼チェック・WordParty 演出のワンタップ発動＆演出追加/編集/削除/素材アップロード・投票・参加型キュー・カウンター・抽選・機能 ON/OFF に対応し、PC 側アプリと他の LAN クライアント間で設定がリアルタイムに双方向同期されます。

### 12. OBS Studio ブラウザソース ＆ デザインカスタマイズ（プリセット・背景色・フォント・カスタム CSS）
- 以下の **9 つのオーバーレイ画面** をローカル URL として内蔵しています（OBS の「ブラウザ」ソースに貼るだけで利用可能）：
  - **コメント表示**: `http://127.0.0.1:18765/overlay/comments`
  - **スパチャ・メンバー表示**: `http://127.0.0.1:18765/overlay/superchat`
  - **コメントピックアップ**: `http://127.0.0.1:18765/overlay/pickup`
  - **リアルタイム投票**: `http://127.0.0.1:18765/overlay/poll`
  - **参加型キュー**: `http://127.0.0.1:18765/overlay/queue`
  - **WordParty 演出・動画**: `http://127.0.0.1:18765/overlay/media`
  - **抽選結果・演出**: `http://127.0.0.1:18765/overlay/lottery`
  - **ワードカウンター**: `http://127.0.0.1:18765/overlay/counter`
  - **初見カウンター**: `http://127.0.0.1:18765/overlay/first_time`
- すべてのオーバーレイごとに **5 種類のデザインプリセット**、**背景色の切り替え（透過／クロマキー緑・青／単色／任意 HEX）**、**OS にインストール済みのシステムフォント選択**、および **ユーザー独自のカスタム CSS** をリアルタイム反映できます。

### 13. 自動アップデート ＆ リリースノート表示
- 新しいバージョンが GitHub に公開されると自動で通知し、アプリ内からそのまま最新版へアップデートできます。
- アップデート後の初回起動時には、そのバージョンで何が変わったか（リリースノート）を自動で表示します。

### 14. 各機能の ON / OFF 切り替え ＆ ライト／ダークモード
- 全 15 機能を配信スタイルに合わせて **個別に ON / OFF** できます。
- 「設定・機能管理」画面から **ライトモード / ダークモード / システム設定に従う** を切り替えられます。

## 動作環境

- **OS**: Windows 10 / Windows 11 (64bit)
- 管理者権限は不要です（ユーザー領域へ安全にインストールされます）。

---

## インストール方法

1. [GitHub Releases](https://github.com/tako-kun1/stosup/releases) ページから最新版の `Stosup-vX.Y.Z-x64.msi` をダウンロードします。
2. ダウンロードした `.msi` ファイルを実行し、日本語の利用規約を確認・同意のうえ、お好みのインストール先フォルダー（既定は `%LOCALAPPDATA%\Stosup`、管理者権限不要）へインストールしてください。
3. スタートメニューまたはデスクトップの「Stosup」から起動します。

## かんたんな使い方

### Step 1: 配信に接続する
1. 画面上部の入力欄に **YouTube Live の配信 URL**（または 11 文字の動画 ID）を貼り付け、「接続」をクリックします。
   - 通常のコメント取得（InnerTube モード）はログイン設定なしですぐに利用できます。
   - 配信をしていない状態で試したい場合は、**「デモ配信」ボタン**から仮想コメントを使って全機能を体験できます。

### Step 2: OBS Studio にオーバーレイを追加する（任意）
1. Stosup の「OBS オーバーレイ」メニューから使いたいオーバーレイの URL をコピーします。
2. OBS Studio でソースの「＋」→「ブラウザ」を追加し、コピーした URL を貼り付けます。
3. 背景は自動で透過されるため、そのまま配信画面の好きな位置に配置できます。

### Step 3: コメント抽選の自動投稿を使う場合（YouTube OAuth 連携）
- コメント抽選で開始コメント・終了コメントを YouTube チャットへ自動投稿する場合は、「設定」画面の **YouTube アカウント連携 (OAuth 2.0)** で Google アカウントを連携してください。

---

## アップデート方法

1. 新バージョンが公開されると、Stosup 起動時または「設定」→「アップデートを確認」から通知が表示されます。
2. 変更内容を確認し「ダウンロードしてアップデート」をクリックすると、自動で最新版をインストールして再起動します。
3. 再起動後に変更点（リリースノート）が表示されます。
